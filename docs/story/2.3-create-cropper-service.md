## 1. Objective

Extract the `process_segment()` and `crop_frame_by_bbox()` functions from `VideoDetector3.ipynb` into `app/services/cropper.py`. This module must:

- Take a source video path and a list of `Segment` objects.
- For each segment, subclip the video, crop every frame to the segment's bbox, and export as MP4 with audio.
- Write output files to a job-specific output directory (`storage/outputs/{job_id}/`).
- Use encoding settings from config (`crf_value`, `video_codec`, `audio_codec`, `ffmpeg_preset`, `ffmpeg_threads`).
- Process segments sequentially (not in a thread pool — see Design Decisions).

    file_name: str

### 4.2 Public API

```python
def crop_segments(
    video_path: str,
    segments: list[Segment],
    output_dir: str,
) -> CropResult:
    """Crop and export each segment from the source video.

    For each segment:
    1. Subclip the video to [start_seconds, end_seconds].
    2. Apply per-frame bbox cropping.
    3. Export as MP4 with audio using configured codec settings.

    Args:
        video_path: Absolute path to the source video file.
        segments: List of Segment objects from the segmenter.
        output_dir: Directory to write output MP4 files into.

    Returns:
        CropResult with list of CroppedSegment metadata.
    """
    output_path = Path(output_dir)
    output_path.mkdir(parents=True, exist_ok=True)

    # Get video duration for clamping end times
    source_video = VideoFileClip(video_path)
    max_duration = source_video.duration
    source_video.close()

    result = CropResult(output_dir=output_dir)

    for segment in segments:
        try:
            cropped = _export_segment(
                video_path=video_path,
                segment=segment,
                output_dir=output_path,
                max_duration=max_duration,
            )
            result.segments.append(cropped)
        except Exception:
            logger.exception(
                "Failed to export segment %d (%s → %s)",
                segment.index, segment.start_time, segment.end_time,
            )

    logger.info(
        "Cropping complete — %d/%d segments exported to %s",
        len(result.segments), len(segments), output_dir,
    )

    return result
```

### 4.3 Internal Helpers

```python
def _export_segment(
    video_path: str,
    segment: Segment,
    output_dir: Path,
    max_duration: float,
) -> CroppedSegment:
    """Export a single cropped segment as MP4.

    Direct refactor of the notebook's process_segment() function.
    """
    file_name = f"segment_{segment.index:06d}.mp4"
    file_path = output_dir / file_name

    logger.info(
        "Exporting segment %d: %s → %s (%ds)",
        segment.index, segment.start_time, segment.end_time,
        segment.duration_seconds,
    )

    video = VideoFileClip(video_path)

    try:
        # Clamp end time to video duration (matches notebook logic)
        end_time = min(segment.end_seconds, max_duration)
        subclip = video.subclipped(segment.start_seconds, end_time)

        # Build per-frame crop function using this segment's bbox
        bbox = segment.bbox

        def crop_frame(frame):
            return _crop_frame_by_bbox(frame, bbox)

        cropped_subclip = subclip.image_transform(crop_frame)

        # Export with configured encoding settings
        temp_audio = str(file_path) + "_temp_audio.m4a"

        cropped_subclip.write_videofile(
            str(file_path),
            codec=settings.video_codec,
            audio_codec=settings.audio_codec,
            preset=settings.ffmpeg_preset,
            threads=settings.ffmpeg_threads,
            temp_audiofile=temp_audio,
            remove_temp=True,
            ffmpeg_params=["-crf", str(settings.crf_value)],
            logger=None,  # Suppress moviepy progress bars
        )

    finally:
        video.close()

    logger.info("Exported: %s (segment %d)", file_name, segment.index)

    return CroppedSegment(
        index=segment.index,
        file_path=str(file_path),
        file_name=file_name,
        start_seconds=segment.start_seconds,
        end_seconds=segment.end_seconds,
        duration_seconds=segment.duration_seconds,
        bbox=segment.bbox,
    )


def _crop_frame_by_bbox(frame, bbox: list[float]):
    """Crop a single video frame to the bounding box.

    Direct port of the notebook's crop_frame_by_bbox(). Ensures:
    - Coordinates are clamped to frame boundaries.
    - Width and height are even numbers (required by H.264/libx264).

    Args:
        frame: numpy array (H, W, C) from MoviePy.
        bbox: [x_min, y_min, width, height] in pixel coordinates.

    Returns:
        Cropped numpy array.
    """
    x_min, y_min, w, h = [int(coord) for coord in bbox]

    # Clamp origin to frame bounds
    x_min = max(0, x_min)
    y_min = max(0, y_min)

    # Ensure even dimensions (H.264 requirement)
    if w % 2 != 0:
        w -= 1
    if h % 2 != 0:
        h -= 1

    # Clamp to frame edges
    x_max = min(frame.shape[1], x_min + w)
    y_max = min(frame.shape[0], y_min + h)

    return frame[y_min:y_max, x_min:x_max]
```

## 7. Design Decisions

| Decision                                          | Rationale                                                                                         |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| **Sequential export instead of ThreadPoolExecutor** | The notebook uses `ThreadPoolExecutor` for parallel segment export. However, each `write_videofile` call spawns FFmpeg subprocesses that are already multi-threaded (`threads=4`). Parallel execution causes FFmpeg processes to compete for CPU/disk I/O, often making total time *worse*. Sequential is simpler and avoids resource contention. |
| **`video.close()` in `finally` block**            | The notebook never explicitly closes `VideoFileClip`. This leaks file handles, which matters in a long-running server. |
| **`segment_{index:06d}.mp4` naming**              | The notebook names files after the input video + timestamp. For the API, predictable index-based names make the download endpoint (`/segments/{index}/download`) straightforward. |
| **Skip check removed (`if not os.path.exists`)** | The notebook skips export if the file already exists. In the API, each job gets a fresh output directory, so this check is unnecessary. |
| **`logger=None` in `write_videofile`**            | Suppresses MoviePy's per-frame progress bars that would flood server logs. Progress is tracked at the pipeline level (Story 2.4). |

## 8. Notes

- **No OpenCV in this module.** Frame reading is handled by MoviePy's internal FFmpeg pipeline (`VideoFileClip` → `subclipped` → `image_transform`). OpenCV is only used in the detector (Story 2.1) for sampling frames for YOLO inference.
- **`_crop_frame_by_bbox` receives raw numpy arrays** from MoviePy's `image_transform`. The frame format is `(H, W, C)` RGB — same as the notebook.
- **Temp audio files** (`_temp_audio.m4a`) are created by MoviePy during muxing and automatically cleaned up via `remove_temp=True`. If the process crashes mid-export, orphan temp files may remain. Story 4.7 (job TTL cleanup) handles this.
- **The `crop_segments` function is sync** (not async). It runs inside the background worker (Story 4.3), which has its own thread/process. No need for async I/O here since FFmpeg is CPU-bound.
