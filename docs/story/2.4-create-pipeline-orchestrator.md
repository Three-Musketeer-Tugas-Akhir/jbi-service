## 1. Objective

Create the top-level orchestrator that wires the three services together into a single `run_pipeline()` call. This is what the background worker (Story 4.3) will invoke for each job. It must:

- Call detector → segmenter → cropper in sequence.
- Track progress across all three phases and report it via a callback.
- Write the `detection_times.txt` file into the output directory.
- Return a single `PipelineResult` dataclass that contains everything the API needs.
- Handle errors at each phase and propagate them with context.

## 3. How It Maps to the Notebook

The notebook's cell-2 runs all three phases inline in a single script:

```
1. Load model + video → detect per second    (detector)
2. split_video() → find segments              (segmenter)
3. ThreadPoolExecutor → process_segment()     (cropper)
```

`pipeline.py` replaces this monolithic flow with explicit orchestration:

```
run_pipeline(job_id, video_path)
  ├─ Phase 1: detector.detect(video_path)        → DetectionResult
  ├─ Phase 2: segmenter.identify_segments(...)    → SegmentationResult
  ├─ Phase 3: cropper.crop_segments(...)          → CropResult
  ├─ Write detection_times.txt
  └─ Return PipelineResult
```

## 4. Detailed Implementation

### 4.1 Data Classes & Imports

```python
from dataclasses import dataclass
from pathlib import Path
from typing import Callable, Optional
from enum import Enum
import logging

from app.config import settings
from app.services.detector import DetectionResult, get_detector
from app.services.segmenter import (
    SegmentationResult,
    identify_segments,
    format_detection_times,
)
from app.services.cropper import CropResult, crop_segments

logger = logging.getLogger(__name__)


class PipelinePhase(str, Enum):
    DETECTION = "detection"
    SEGMENTATION = "segmentation"
    CROPPING = "cropping"


# Progress callback: (phase, current_step, total_steps) -> None
PipelineProgressCallback = Callable[[str, int, int], None]


class PipelineError(Exception):
    """Raised when a pipeline phase fails."""

    def __init__(self, phase: PipelinePhase, message: str):
        self.phase = phase
        super().__init__(f"[{phase.value}] {message}")


@dataclass
class PipelineResult:
    """Complete output of the full detect → segment → crop pipeline."""
    job_id: str
    video_path: str
    output_dir: str
    detection: DetectionResult
    segmentation: SegmentationResult
    crop: CropResult
    detection_times_path: str  # path to detection_times.txt
```

---

### 4.2 Public API

```python
def run_pipeline(
    job_id: str,
    video_path: str,
    on_progress: Optional[PipelineProgressCallback] = None,
) -> PipelineResult:
    """Execute the full detection → segmentation → cropping pipeline.

    This is the single entry point called by the background worker.
    It orchestrates all three services and returns a unified result.

    Args:
        job_id: Unique job identifier (used for output directory naming).
        video_path: Absolute path to the uploaded video file.
        on_progress: Optional callback for progress reporting.
                     Called with (phase_name, current_step, total_steps).

    Returns:
        PipelineResult with all phase outputs.

    Raises:
        PipelineError: If any phase fails, wrapping the original exception.
    """
    output_dir = str(Path(settings.output_dir) / job_id)
    Path(output_dir).mkdir(parents=True, exist_ok=True)

    logger.info("Pipeline started — job=%s, video=%s", job_id, video_path)

    # ---- Phase 1: Detection ----
    detection_result = _run_detection(video_path, on_progress)

    # ---- Phase 2: Segmentation ----
    segmentation_result = _run_segmentation(detection_result, on_progress)

    # ---- Phase 3: Cropping ----
    crop_result = _run_cropping(
        video_path, segmentation_result, output_dir, on_progress,
    )

    # ---- Write detection_times.txt ----
    detection_times_path = _write_detection_times(
        segmentation_result, output_dir,
    )

    result = PipelineResult(
        job_id=job_id,
        video_path=video_path,
        output_dir=output_dir,
        detection=detection_result,
        segmentation=segmentation_result,
        crop=crop_result,
        detection_times_path=detection_times_path,
    )

    logger.info(
        "Pipeline complete — job=%s, segments=%d, output=%s",
        job_id, len(segmentation_result.segments), output_dir,
    )

    return result
```

### 4.3 Phase Runners

```python
def _run_detection(
    video_path: str,
    on_progress: Optional[PipelineProgressCallback],
) -> DetectionResult:
    """Phase 1: Run YOLO detection on every second of the video."""
    logger.info("Phase 1/3: Detection — starting")

    def detection_progress(current_second: int, total_seconds: int):
        if on_progress:
            on_progress(PipelinePhase.DETECTION, current_second, total_seconds)

    try:
        detector = get_detector()
        result = detector.detect(video_path, on_progress=detection_progress)
    except Exception as exc:
        raise PipelineError(PipelinePhase.DETECTION, str(exc)) from exc

    logger.info(
        "Phase 1/3: Detection — done (%d/%d seconds with detections)",
        sum(result.detections), len(result.detections),
    )
    return result


def _run_segmentation(
    detection_result: DetectionResult,
    on_progress: Optional[PipelineProgressCallback],
) -> SegmentationResult:
    """Phase 2: Identify contiguous detection segments."""
    logger.info("Phase 2/3: Segmentation — starting")

    # Segmentation is near-instant (pure in-memory logic).
    # Report as single-step progress.
    if on_progress:
        on_progress(PipelinePhase.SEGMENTATION, 0, 1)

    try:
        result = identify_segments(detection_result)
    except Exception as exc:
        raise PipelineError(PipelinePhase.SEGMENTATION, str(exc)) from exc

    if on_progress:
        on_progress(PipelinePhase.SEGMENTATION, 1, 1)

    logger.info(
        "Phase 2/3: Segmentation — done (%d segments found)",
        len(result.segments),
    )
    return result


def _run_cropping(
    video_path: str,
    segmentation_result: SegmentationResult,
    output_dir: str,
    on_progress: Optional[PipelineProgressCallback],
) -> CropResult:
    """Phase 3: Crop and export each segment as MP4."""
    segments = segmentation_result.segments

    if not segments:
        logger.info("Phase 3/3: Cropping — skipped (no segments)")
        if on_progress:
            on_progress(PipelinePhase.CROPPING, 0, 0)
        return CropResult(output_dir=output_dir)

    logger.info("Phase 3/3: Cropping — starting (%d segments)", len(segments))

    if on_progress:
        on_progress(PipelinePhase.CROPPING, 0, len(segments))

    try:
        result = crop_segments(video_path, segments, output_dir)
    except Exception as exc:
        raise PipelineError(PipelinePhase.CROPPING, str(exc)) from exc

    if on_progress:
        on_progress(PipelinePhase.CROPPING, len(segments), len(segments))

    logger.info("Phase 3/3: Cropping — done (%d files)", len(result.segments))
    return result


def _write_detection_times(
    segmentation_result: SegmentationResult,
    output_dir: str,
) -> str:
    """Write the detection_times.txt summary file.

    Equivalent to the notebook's file write inside split_video().
    """
    content = format_detection_times(segmentation_result.segments)
    file_path = Path(output_dir) / "detection_times.txt"
    file_path.write_text(content, encoding="utf-8")
    logger.debug("Wrote detection_times.txt to %s", file_path)
    return str(file_path)
```

## 5. Progress Callback Flow

The `on_progress` callback enables the job manager (Story 4.4) to update job status in real time. Here's how progress flows through the pipeline:

```
Phase               Callback calls                           Example (60s video, 3 segments)
─────────────────── ──────────────────────────────────────── ─────────────────────────────────
Detection           (detection, current_sec, total_sec)      (detection, 8, 60)
                                                             (detection, 16, 60)
                                                             ...
                                                             (detection, 60, 60)

Segmentation        (segmentation, 0, 1)                     (segmentation, 0, 1)
                    (segmentation, 1, 1)                     (segmentation, 1, 1)

Cropping            (cropping, 0, num_segments)              (cropping, 0, 3)
                    (cropping, num_segments, num_segments)    (cropping, 3, 3)
```

The background worker (Story 4.3) will translate these into the job progress fields:

```python
# In workers/tasks.py (Story 4.3):
def progress_handler(phase: str, current: int, total: int):
    job_store.update_progress(job_id, phase=phase, current=current, total=total)
```

The status endpoint (Story 4.5) will expose this as:

```json
{
  "progress": {
    "phase": "detection",
    "current_second": 340,
    "total_seconds": 3400,
    "percent": 10.0
  }
}
```

## 7. Design Decisions

| Decision                                          | Rationale                                                                                         |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| **Single `run_pipeline()` entry point**           | The worker (Story 4.3) calls one function. It doesn't need to know about detector/segmenter/cropper internals. |
| **`PipelineError` wraps phase failures**          | Lets the worker report *which* phase failed without parsing exception types. The job status can show `"error in detection"` vs `"error in cropping"`. |
| **Segmentation progress is 0→1**                  | Segmentation is pure in-memory list traversal (<1ms). No need for granular progress. Reporting 0/1 and 1/1 keeps the callback contract consistent. |
| **Skip cropping if no segments**                  | Avoids opening `VideoFileClip` unnecessarily. Returns an empty `CropResult` so the API result structure is always consistent. |
| **`detection_times.txt` written by pipeline**     | The segmenter returns a string (no I/O). The pipeline owns the output directory and does the write. This keeps the segmenter pure and testable. |
| **`PipelineResult` bundles all phase outputs**    | The results endpoint (Story 5.1) needs data from all three phases (metadata from detector, segments from segmenter, file paths from cropper). Bundling them avoids re-reading from disk. |

---

## 8. Notes

- **Thread safety:** `run_pipeline()` is synchronous and blocking. It's designed to run inside a background worker thread/process (Story 4.3). Only one pipeline should run per worker at a time — this is enforced by the job concurrency limit (`settings.max_concurrent_jobs`).
- **Memory:** The `DetectionResult.detections` list holds one boolean per second of video. For a 2-hour video that's ~7,200 booleans — negligible. The `bboxes` dict holds 4 floats per detected second — also negligible.
- **Disk:** The pipeline creates `storage/outputs/{job_id}/` with one MP4 per segment plus `detection_times.txt`. Cleanup is handled by Story 4.7 (job TTL).
- **Future enhancement:** Per-segment progress during cropping (reporting after each segment export) can be added by extending `crop_segments()` to accept a callback. Deferred to keep this story focused.
