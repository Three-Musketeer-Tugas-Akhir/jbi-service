## 1. Objective

Replace the placeholder `POST /api/v1/jobs` stub (from Story 1.1) with a fully functional endpoint that:

- Accepts a video file via `multipart/form-data`.
- Validates file extension and size against config.
- Probes the file with OpenCV to verify it's a valid, readable video.
- Saves the file to `storage/uploads/{job_id}.{ext}`.
- Creates a job record with `queued` status.
- Enqueues the pipeline as a background task.
- Returns `202 Accepted` with `job_id`, `status`, and `created_at`.

> **Note:** This story combines Stories 3.1 + 3.3 + 3.4 + 3.5 from the PRD since they are tightly coupled and form a single coherent feature. Implementing them separately would require the endpoint to be rewritten multiple times.

### 3.3 Job Store — `app/models/job_store.py`

In-memory job store (MVP). Interface is designed for future DB swap (Story 4.2).

```python
import threading
from datetime import datetime, timezone
from typing import Optional

from app.models.job import Job, JobStatus, JobProgress


class JobStore:
    """Thread-safe in-memory job store.

    MVP implementation using a dict + lock.
    Interface is kept minimal so it can be swapped to a DB later.
    """

    def __init__(self):
        self._jobs: dict[str, Job] = {}
        self._lock = threading.Lock()

    def create(self, job: Job) -> Job:
        with self._lock:
            self._jobs[job.job_id] = job
        return job

    def get(self, job_id: str) -> Optional[Job]:
        with self._lock:
            return self._jobs.get(job_id)

    def update_status(self, job_id: str, status: JobStatus, error: str = None):
        with self._lock:
            job = self._jobs.get(job_id)
            if job:
                job.status = status
                job.updated_at = datetime.now(timezone.utc)
                if error:
                    job.error = error

    def update_progress(
        self, job_id: str, phase: str, current: int, total: int,
    ):
        with self._lock:
            job = self._jobs.get(job_id)
            if job:
                job.progress = JobProgress(
                    phase=phase,
                    current=current,
                    total=total,
                    percent=round((current / total * 100) if total > 0 else 0, 1),
                )
                job.updated_at = datetime.now(timezone.utc)

    def set_result(self, job_id: str, result: object):
        with self._lock:
            job = self._jobs.get(job_id)
            if job:
                job.result = result

    def delete(self, job_id: str) -> bool:
        with self._lock:
            return self._jobs.pop(job_id, None) is not None

    def list_all(self) -> list[Job]:
        with self._lock:
            return list(self._jobs.values())


# Module-level singleton
job_store = JobStore()
```

### 3.4 Video Validation Utility — `app/services/validator.py`

```python
import os
from pathlib import Path

import cv2

from app.config import settings


class VideoValidationError(Exception):
    """Raised when a video file fails validation."""
    pass


def validate_upload(file_name: str, file_size: int) -> None:
    """Validate file extension and size before saving.

    Args:
        file_name: Original filename from the upload.
        file_size: File size in bytes.

    Raises:
        VideoValidationError: If validation fails.
    """
    ext = Path(file_name).suffix.lower()
    if ext not in settings.allowed_extensions_list:
        raise VideoValidationError(
            f"File extension '{ext}' not allowed. "
            f"Accepted: {', '.join(settings.allowed_extensions_list)}"
        )

    if file_size > settings.max_upload_size_bytes:
        max_mb = settings.max_upload_size_mb
        actual_mb = round(file_size / (1024 * 1024), 1)
        raise VideoValidationError(
            f"File size {actual_mb} MB exceeds maximum {max_mb} MB"
        )


def validate_video_file(file_path: str) -> None:
    """Probe a saved file with OpenCV to verify it's a valid video.

    Args:
        file_path: Path to the saved video file on disk.

    Raises:
        VideoValidationError: If the file is not a valid video.
    """
    cap = cv2.VideoCapture(file_path)

    try:
        if not cap.isOpened():
            raise VideoValidationError(
                "File is not a valid video or cannot be opened"
            )

        fps = cap.get(cv2.CAP_PROP_FPS)
        frame_count = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))

        if fps == 0:
            raise VideoValidationError("Could not read FPS from video")

        if frame_count == 0:
            raise VideoValidationError("Video has zero frames")

        # Try reading the first frame to confirm the file is actually decodable
        ret, frame = cap.read()
        if not ret or frame is None:
            raise VideoValidationError("Cannot decode first frame of video")

    finally:
        cap.release()
```

### 3.5 Background Task Worker — `app/workers/tasks.py`

```python
import logging
from app.models.job import JobStatus
from app.models.job_store import job_store
from app.services.pipeline import run_pipeline, PipelineError

logger = logging.getLogger(__name__)


def process_job(job_id: str, video_path: str) -> None:
    """Background task that runs the full pipeline for a job.

    Called by FastAPI's BackgroundTasks. Updates job store with
    progress, status, and results.
    """
    logger.info("Starting job %s", job_id)
    job_store.update_status(job_id, JobStatus.PROCESSING)

    def on_progress(phase, current, total):
        job_store.update_progress(job_id, phase=phase, current=current, total=total)

    try:
        result = run_pipeline(
            job_id=job_id,
            video_path=video_path,
            on_progress=on_progress,
        )
        job_store.set_result(job_id, result)
        job_store.update_status(job_id, JobStatus.COMPLETED)
        logger.info("Job %s completed — %d segments", job_id, len(result.segmentation.segments))

    except PipelineError as exc:
        logger.exception("Job %s failed at phase %s", job_id, exc.phase)
        job_store.update_status(job_id, JobStatus.FAILED, error=str(exc))

    except Exception as exc:
        logger.exception("Job %s failed with unexpected error", job_id)
        job_store.update_status(job_id, JobStatus.FAILED, error=str(exc))
```

### 3.6 Router Implementation — `app/routers/jobs.py`

```python
import uuid
import logging
from pathlib import Path

from fastapi import APIRouter, UploadFile, File, BackgroundTasks, HTTPException

from app.config import settings
from app.models.schemas import JobCreateResponse, ErrorResponse
from app.models.job import Job
from app.models.job_store import job_store
from app.services.validator import validate_upload, validate_video_file, VideoValidationError
from app.workers.tasks import process_job

logger = logging.getLogger(__name__)

router = APIRouter()


@router.post(
    "/jobs",
    status_code=202,
    response_model=JobCreateResponse,
    responses={400: {"model": ErrorResponse}},
)
async def create_job(
    background_tasks: BackgroundTasks,
    file: UploadFile = File(...),
):
    """Upload a video and start a detection job.

    Accepts a video file via multipart/form-data. Validates the file,
    saves it to disk, creates a job record, and enqueues the pipeline
    as a background task.

    Returns 202 Accepted with job_id for status polling.
    """
    # --- Step 1: Validate file metadata ---
    try:
        # Read file content to get size
        content = await file.read()
        file_size = len(content)

        validate_upload(file.filename, file_size)
    except VideoValidationError as exc:
        raise HTTPException(status_code=400, detail=str(exc))

    # --- Step 2: Save file to disk ---
    job_id = str(uuid.uuid4())
    ext = Path(file.filename).suffix.lower()
    upload_dir = Path(settings.upload_dir)
    upload_dir.mkdir(parents=True, exist_ok=True)

    file_path = upload_dir / f"{job_id}{ext}"

    try:
        with open(file_path, "wb") as f:
            f.write(content)
    except IOError as exc:
        logger.exception("Failed to save uploaded file for job %s", job_id)
        raise HTTPException(status_code=500, detail="Failed to save uploaded file")

    # --- Step 3: Validate video content ---
    try:
        validate_video_file(str(file_path))
    except VideoValidationError as exc:
        # Clean up the invalid file
        file_path.unlink(missing_ok=True)
        raise HTTPException(status_code=400, detail=str(exc))

    # --- Step 4: Create job record ---
    job = Job(job_id=job_id, video_path=str(file_path))
    job_store.create(job)

    logger.info(
        "Job created: id=%s, file=%s, size=%d bytes",
        job_id, file.filename, file_size,
    )

    # --- Step 5: Enqueue background processing ---
    background_tasks.add_task(process_job, job_id, str(file_path))

    return JobCreateResponse(
        job_id=job.job_id,
        status=job.status.value,
        created_at=job.created_at,
    )
```

```
  │                               │  1. Read file bytes            │
  │                               │  2. validate_upload()          │
  │                               │     ├─ check extension         │
  │                               │     └─ check size              │
  │                               │                                │
  │                               │  3. Generate UUID job_id       │
  │                               │  4. Save to uploads/{id}.mp4 ──>│
  │                               │                                │
  │                               │  5. validate_video_file()      │
  │                               │     ├─ cv2.VideoCapture        │
  │                               │     ├─ check FPS > 0           │
  │                               │     ├─ check frames > 0        │
  │                               │     └─ decode first frame      │
  │                               │                                │
  │                               │  6. Create Job(status=queued)──>│ job_store
  │                               │  7. Enqueue background task    │
  │                               │                                │
  │  202 Accepted                 │                                │
  │  {"job_id": "...",            │                                │
  │   "status": "queued",         │                                │
  │   "created_at": "..."}        │                                │
  │<──────────────────────────────│                                │
  │                               │                                │
  │                               │  [Background] process_job()    │
  │                               │  ├─ status → processing        │
```

## 7. Design Decisions

| Decision                                     | Rationale                                                                                          |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **Read entire file into memory then save**    | Simplifies size validation. For 2 GB max files, this is acceptable on a server with ≥4 GB RAM. A streaming approach (chunked read) can be added later if needed. |
| **Validate extension before saving**          | Avoids writing garbage files to disk. Fast check on filename only.                                |
| **Validate video after saving**               | OpenCV needs a file path — it can't probe bytes in memory. Save first, validate, delete if invalid.|
| **UUID4 for job_id**                          | No collision risk, no sequence guessing, URL-safe.                                                |
| **Cleanup on validation failure**             | If `validate_video_file` fails, the uploaded file is deleted to avoid orphan files.               |
| **BackgroundTasks (not Celery)**              | MVP simplicity. Story 4.3 already defines the task function interface, so swapping to Celery later is a config change, not a rewrite. |
| **Combined stories 3.1 + 3.3 + 3.4 + 3.5**  | Upload, validation, and job creation are a single atomic flow. Splitting them into separate PRs would mean a non-functional endpoint after each merge. |

## 8. Notes

- **Story 3.2 (URL ingestion)** will reuse `validate_video_file()` and the job creation logic. The difference is downloading from a URL instead of receiving an upload — the rest of the flow is identical.
- **File size limit:** Reading the full file into memory caps at `MAX_UPLOAD_SIZE_MB` (default 2 GB). For truly large files, a streaming approach with `file.read(chunk_size)` in a loop would be needed. This is a future enhancement.
- **`content = await file.read()`** reads the entire file. FastAPI's `UploadFile` spools files >1 MB to a temp file on disk automatically (`python-multipart` behavior), so memory usage is reasonable even for large uploads.
- **The `process_job` function** (Section 3.5) will also be used by Story 3.2 (URL jobs) since it only needs `job_id` and `video_path`.
