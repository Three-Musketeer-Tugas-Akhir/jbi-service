## 1. Objective

Create a centralized, type-safe configuration system so that every module reads its settings from one place. The system must:

- Load values from environment variables / `.env` file using `pydantic-settings`.
- Provide sensible defaults so the app starts with zero config on a dev machine.
- Cover all backend-only pipeline settings (FR-5.1) and infra settings (CORS, storage, TTL).
- Expose a singleton `settings` instance importable as `from app.config import settings`.

## 4. Detailed Implementation

### 4.1 `app/config.py`

```python
from pathlib import Path
from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    model_config = SettingsConfigDict(
        env_file=".env",
        env_file_encoding="utf-8",
        case_sensitive=False,
    )

    # --- Model & Pipeline ---
    model_path: str = "model_weights/best.pt"
    processing_mode: str = "auto"  # "auto", "cpu", "gpu"
    batch_size: int = 8
    min_segment_duration: int = 5
    crf_value: int = 16
    video_codec: str = "libx264"
    audio_codec: str = "aac"
    ffmpeg_preset: str = "veryslow"
    ffmpeg_threads: int = 4

    # --- Storage ---
    upload_dir: str = "storage/uploads"
    output_dir: str = "storage/outputs"

    # --- Upload & Validation ---
    max_upload_size_mb: int = 2048
    allowed_extensions: str = ".mp4,.avi,.mkv,.mov"

    # --- Job Management ---
    job_ttl_hours: int = 24
    max_concurrent_jobs: int = 3

    # --- Server ---
    cors_origins: str = "*"
    api_v1_prefix: str = "/api/v1"

    @property
    def max_upload_size_bytes(self) -> int:
        return self.max_upload_size_mb * 1024 * 1024

    @property
    def allowed_extensions_list(self) -> list[str]:
        return [ext.strip() for ext in self.allowed_extensions.split(",")]

    @property
    def cors_origins_list(self) -> list[str]:
        return [origin.strip() for origin in self.cors_origins.split(",")]


settings = Settings()
```

**Key design choices:**

- `model_config` with `case_sensitive=False` so `MODEL_PATH` and `model_path` both work as env vars.
- Comma-separated strings for list-like values (`CORS_ORIGINS`, `ALLOWED_EXTENSIONS`) with `@property` helpers to split them. This avoids complex env var parsing.
- A module-level `settings = Settings()` singleton — import once, use everywhere.

### 4.3 Update `app/main.py`

Apply CORS middleware using settings and use `API_V1_PREFIX` for router registration.

```python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from app.config import settings
from app.routers import health, jobs

app = FastAPI(
    title="JBI Detection & Segmentation API",
    version="1.0.0",
    description="API for detecting and segmenting JBI overlays in news broadcast videos.",
)

# CORS middleware
app.add_middleware(
    CORSMiddleware,
    allow_origins=settings.cors_origins_list,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

app.include_router(health.router, prefix=settings.api_v1_prefix, tags=["health"])
app.include_router(jobs.router, prefix=settings.api_v1_prefix, tags=["jobs"])


@app.get("/")
async def root():
    return {"message": "JBI Detection & Segmentation API"}
```

**Changes from Story 1.1:**
- Import `settings` and `CORSMiddleware`.
- Add CORS middleware with origins from config.
- Use `settings.api_v1_prefix` instead of hardcoded `"/api/v1"`.

## 5. How to Verify

```bash
# 1. Start with NO .env file (defaults should work)
uvicorn app.main:app --reload
# Server starts on 0.0.0.0:8000 — no errors

# 2. Verify settings load correctly

print(f'model_path:        {settings.model_path}')

"

# 3. Override via environment variable
set MODEL_PATH=custom_model.pt
python -c "from app.config import settings; print(settings.model_path)"
# Expected: custom_model.pt

# 4. Override via .env file
# Copy .env.example to .env, change BATCH_SIZE=16
python -c "from app.config import settings; print(settings.batch_size)"
# Expected: 16

# 5. Verify CORS header is present
curl -i -X OPTIONS http://localhost:8000/api/v1/health \
  -H "Origin: http://localhost:3000" \
  -H "Access-Control-Request-Method: GET"
# Response should include: access-control-allow-origin: *
```

## 6. Notes

- **No `.env` file is committed.** Only `.env.example` is tracked in git. Story 1.5 will add `.env` to `.gitignore`.
- **`processing_mode: "auto"`** logic (detect CUDA availability) is not implemented here — that lives in `services/detector.py` (Story 2.1). Config just stores the user's preference.
- **`FFMPEG_PRESET=veryslow`** matches the notebook default. Can be changed to `medium` or `fast` for quicker encoding at the cost of file size.
