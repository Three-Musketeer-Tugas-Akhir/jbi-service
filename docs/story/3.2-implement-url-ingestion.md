# Story 3.2 — Implement URL-Based Video Ingestion

| Field          | Value                                                                                  |
| -------------- | -------------------------------------------------------------------------------------- |
| **Epic**       | 3 — Video Ingestion & Validation                                                       |
| **Priority**   | P1                                                                                     |
| **Summary**    | Implement URL-based ingestion: download video from provided URL to `uploads/`           |
| **Depends on** | 3.1 (upload endpoint, job model, job store, validator, background task)                 |
| **Blocks**     | None (parallel path to file upload)                                                    |

---

## 1. Objective

Extend `POST /api/v1/jobs` to accept a `url` form field as an alternative to a `file` upload. The backend downloads the video from the given URL, then runs through the same validation → save → enqueue flow established in Story 3.1.

This enables:

- Researchers batch-processing videos via scripts (pass a URL, no multipart needed).
- Internal services sending video URLs from an existing storage system.

---

## 2. Acceptance Criteria

| #    | Criteria                                                                                               |
| ---- | ------------------------------------------------------------------------------------------------------ |
| AC-1 | `POST /api/v1/jobs` with form field `url` (and no `file`) downloads the video and creates a job.       |
| AC-2 | Returns `400` if both `file` and `url` are omitted.                                                    |
| AC-3 | Returns `400` if URL is not reachable or returns non-2xx status.                                       |
| AC-4 | Returns `400` if downloaded content exceeds `settings.max_upload_size_bytes`.                           |
| AC-5 | Returns `400` if downloaded file fails extension or video validation.                                  |
| AC-6 | Downloads are streamed in chunks to avoid loading the entire file into memory.                          |
| AC-7 | Downloaded file is saved to `storage/uploads/{job_id}.{ext}` (extension inferred from URL or Content-Type). |
| AC-8 | On success, returns `202` with same `JobCreateResponse` as file upload.                                |
| AC-9 | On download/validation failure, any partially written file is cleaned up.                               |

## 3. Detailed Implementation

### 3.1 Download Utility — `app/services/downloader.py`

```python
import logging
import mimetypes
from pathlib import Path
from urllib.parse import urlparse

import requests

from app.config import settings

logger = logging.getLogger(__name__)

# Map common video MIME types to extensions
MIME_TO_EXT = {
    "video/mp4": ".mp4",
    "video/x-msvideo": ".avi",
    "video/x-matroska": ".mkv",
    "video/quicktime": ".mov",
}

DOWNLOAD_CHUNK_SIZE = 8 * 1024 * 1024  # 8 MB chunks


class DownloadError(Exception):
    """Raised when a video URL download fails."""
    pass


def download_video(url: str, dest_path: str) -> int:
    """Download a video from a URL to a local file path.

    Streams the download in chunks to avoid loading the entire file
    into memory. Validates size during download.

    Args:
        url: Publicly accessible video URL.
        dest_path: Local file path to write to.

    Returns:
        Total downloaded file size in bytes.

    Raises:
        DownloadError: If the download fails for any reason.
    """
    try:
        response = requests.get(url, stream=True, timeout=30)
        response.raise_for_status()
    except requests.ConnectionError:
        raise DownloadError(f"Cannot connect to URL: {url}")
    except requests.Timeout:
        raise DownloadError(f"Connection timed out: {url}")
    except requests.HTTPError as exc:
        raise DownloadError(f"URL returned HTTP {exc.response.status_code}")

    max_bytes = settings.max_upload_size_bytes
    downloaded = 0

    try:
        with open(dest_path, "wb") as f:
            for chunk in response.iter_content(chunk_size=DOWNLOAD_CHUNK_SIZE):
                if chunk:
                    downloaded += len(chunk)
                    if downloaded > max_bytes:
                        raise DownloadError(
                            f"Download exceeds maximum size of "
                            f"{settings.max_upload_size_mb} MB"
                        )
                    f.write(chunk)
    except DownloadError:
        # Clean up partial file
        Path(dest_path).unlink(missing_ok=True)
        raise
    except IOError as exc:
        Path(dest_path).unlink(missing_ok=True)
        raise DownloadError(f"Failed to write file: {exc}")

    logger.info("Downloaded %d bytes from %s", downloaded, url)
    return downloaded


def infer_extension(url: str) -> str:
    """Infer file extension from a URL path or default to .mp4.

    Tries:
    1. Extension from URL path (e.g. /video.mp4 → .mp4)
    2. Falls back to .mp4 if unrecognizable

    Args:
        url: The video URL.

    Returns:
        Extension string including dot (e.g. ".mp4").
    """
    parsed = urlparse(url)
    path_ext = Path(parsed.path).suffix.lower()

    if path_ext in settings.allowed_extensions_list:
        return path_ext

    return ".mp4"
```

### 3.2 Updated Router — `app/routers/jobs.py`

Changes from Story 3.1:

- `file` parameter becomes `Optional`.
- New `url` form field (`Optional[str]`).
- Routing logic: file upload → existing flow, URL → download flow, neither → 400.

```python
import uuid
import logging
from pathlib import Path
from typing import Optional

from fastapi import APIRouter, UploadFile, File, Form, BackgroundTasks, HTTPException

from app.config import settings
from app.models.schemas import JobCreateResponse, ErrorResponse
from app.models.job import Job
from app.models.job_store import job_store
from app.services.validator import (
    validate_upload, validate_video_file, VideoValidationError,
)
from app.services.downloader import download_video, infer_extension, DownloadError
from app.workers.tasks import process_job

logger = logging.getLogger(__name__)

router = APIRouter()


@router.post(
    "/jobs",
    status_code=202,
    response_model=JobCreateResponse,
    responses={400: {"model": ErrorResponse}},
)
async def create_job(
    background_tasks: BackgroundTasks,
    file: Optional[UploadFile] = File(None),
    url: Optional[str] = Form(None),
):
    """Upload a video or provide a URL to start a detection job.

    Provide either a `file` (multipart upload) or a `url` (public video link).
    If both are provided, `file` takes priority.
    """
    if file is None and url is None:
        raise HTTPException(
            status_code=400,
            detail="Either 'file' or 'url' must be provided",
        )

    job_id = str(uuid.uuid4())

    if file is not None:
        file_path = await _handle_file_upload(job_id, file)
    else:
        file_path = _handle_url_download(job_id, url)

    # --- Create job record ---
    job = Job(job_id=job_id, video_path=str(file_path))
    job_store.create(job)

    logger.info("Job created: id=%s, source=%s", job_id, "upload" if file else "url")

    # --- Enqueue background processing ---
    background_tasks.add_task(process_job, job_id, str(file_path))

    return JobCreateResponse(
        job_id=job.job_id,
        status=job.status.value,
        created_at=job.created_at,
    )


async def _handle_file_upload(job_id: str, file: UploadFile) -> Path:
    """Process a multipart file upload. Returns saved file path.

    Same logic as Story 3.1.
    """
    content = await file.read()
    file_size = len(content)

    try:
        validate_upload(file.filename, file_size)
    except VideoValidationError as exc:
        raise HTTPException(status_code=400, detail=str(exc))

    ext = Path(file.filename).suffix.lower()
    upload_dir = Path(settings.upload_dir)
    upload_dir.mkdir(parents=True, exist_ok=True)
    file_path = upload_dir / f"{job_id}{ext}"

    try:
        with open(file_path, "wb") as f:
            f.write(content)
    except IOError:
        logger.exception("Failed to save uploaded file for job %s", job_id)
        raise HTTPException(status_code=500, detail="Failed to save uploaded file")

    try:
        validate_video_file(str(file_path))
    except VideoValidationError as exc:
        file_path.unlink(missing_ok=True)
        raise HTTPException(status_code=400, detail=str(exc))

    return file_path


def _handle_url_download(job_id: str, url: str) -> Path:
    """Download a video from URL. Returns saved file path."""
    ext = infer_extension(url)
    upload_dir = Path(settings.upload_dir)
    upload_dir.mkdir(parents=True, exist_ok=True)
    file_path = upload_dir / f"{job_id}{ext}"

    # Download
    try:
        file_size = download_video(url, str(file_path))
    except DownloadError as exc:
        raise HTTPException(status_code=400, detail=str(exc))

    # Validate extension (inferred ext might not match actual content)
    try:
        validate_upload(f"video{ext}", file_size)
    except VideoValidationError as exc:
        file_path.unlink(missing_ok=True)
        raise HTTPException(status_code=400, detail=str(exc))

    # Validate video content
    try:
        validate_video_file(str(file_path))
    except VideoValidationError as exc:
        file_path.unlink(missing_ok=True)
        raise HTTPException(status_code=400, detail=str(exc))

    return file_path


# --- Remaining stubs (unchanged) ---
```

## 4. Request Flow — URL Path

```
Client                          FastAPI                           Network / Disk
  │                               │                                │
  │  POST /api/v1/jobs            │                                │
  │  url=https://example.com/v.mp4│                                │
  │──────────────────────────────>│                                │
  │                               │                                │
  │                               │  1. No file → use URL path     │
  │                               │  2. infer_extension(url)       │
  │                               │     → ".mp4"                   │
  │                               │                                │
  │                               │  3. download_video(url, path)  │
  │                               │     ├─ GET url (stream=True) ──>│ remote server
  │                               │     ├─ check size per chunk    │
  │                               │     └─ write to disk ──────────>│ uploads/{id}.mp4
  │                               │                                │
  │                               │  4. validate_upload()          │
  │                               │  5. validate_video_file()      │
  │                               │     └─ OpenCV probe            │
  │                               │                                │
  │                               │  6. Create Job + enqueue       │
  │                               │                                │
  │  202 Accepted                 │                                │
  │<──────────────────────────────│                                │
```

## 5. Error Responses (URL-specific)

| Scenario                    | Status | Response body                                                    |
| --------------------------- | ------ | ---------------------------------------------------------------- |
| Neither file nor url given  | 400    | `{"detail": "Either 'file' or 'url' must be provided"}`         |
| URL unreachable             | 400    | `{"detail": "Cannot connect to URL: https://..."}`              |
| URL timeout                 | 400    | `{"detail": "Connection timed out: https://..."}`               |
| URL returns 404             | 400    | `{"detail": "URL returned HTTP 404"}`                           |
| Download exceeds max size   | 400    | `{"detail": "Download exceeds maximum size of 2048 MB"}`        |
| Downloaded file not a video | 400    | `{"detail": "File is not a valid video or cannot be opened"}`   |

## 7. Design Decisions

| Decision                                | Rationale                                                                                          |
| --------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **Streamed download (8 MB chunks)**     | Avoids loading a 2 GB video into memory. Size is validated per-chunk during download.              |
| **Size check during download, not after** | Stops early if the file is too large. Avoids downloading 2 GB only to reject it.                 |
| **`infer_extension` from URL path**     | Most video URLs end with `.mp4`. For ambiguous URLs, default to `.mp4` since it's the most common. OpenCV probe catches any mismatch. |
| **File takes priority over URL**        | Avoids ambiguity when both are sent. The file is already in memory — faster than downloading.     |
| **`requests` library (not httpx)**      | Already a transitive dependency of `ultralytics`. No new dependency added.                        |
| **30s connection timeout**              | Prevents the endpoint from hanging indefinitely on slow URLs. The download itself has no total timeout — large files can take minutes. |
| **Cleanup partial downloads**           | If download is aborted (size exceeded, network error), the partial file is deleted immediately.   |

---

## 8. Notes

- **`requests` is already installed** as a transitive dependency of `ultralytics`. No change to `requirements.txt` needed.
- **Total download time is unbounded** — the 30s timeout is for the initial connection only. A 2 GB file over a slow connection could take minutes. Adding a total timeout is a future enhancement.
- **No authentication on URLs** — the URL must be publicly accessible. Supporting auth headers (Bearer token, API keys) is out of scope for v1.
- **The `file` parameter changed from `File(...)` (required) to `File(None)` (optional)**. This is a breaking change from Story 3.1's Swagger UI but is the correct final signature. Story 3.1's implementation is superseded by this one.
