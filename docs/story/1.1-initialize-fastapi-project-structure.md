## 1. Objective

Create the foundational directory layout and minimal boilerplate files so that:

- `uvicorn app.main:app --reload` starts successfully and returns a response.
- Every package has an `__init__.py` and is importable.
- Storage directories (`uploads/`, `outputs/`) exist and are gitignored.
- The project is ready for subsequent stories to drop in real logic.

#### `app/main.py`

This is the FastAPI application entry point. It:

- Creates the FastAPI app instance with metadata (title, version, description).
- Includes the router stubs from `routers/`.
- Defines a root endpoint for basic connectivity check.

```python
from fastapi import FastAPI
from app.routers import health, jobs

app = FastAPI(
    title="JBI Detection & Segmentation API",
    version="1.0.0",
    description="API for detecting and segmenting JBI overlays in news broadcast videos.",
)

app.include_router(health.router, prefix="/api/v1", tags=["health"])
app.include_router(jobs.router, prefix="/api/v1", tags=["jobs"])


@app.get("/")
async def root():
    return {"message": "JBI Detection & Segmentation API"}
```

### 3.3 How to Verify

```bash
# 1. Install minimal dependency
pip install fastapi uvicorn

# 2. Start the server from the project root
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 3. Test root endpoint
curl http://localhost:8000/
# Expected: {"message":"JBI Detection & Segmentation API"}

# 4. Test health endpoint
curl http://localhost:8000/api/v1/health
# Expected: {"status":"ok"}

# 5. Test stub job endpoint
curl -X POST http://localhost:8000/api/v1/jobs
# Expected: {"message":"not implemented"} with 202 status

# 6. Verify OpenAPI docs load
# Open http://localhost:8000/docs in browser — Swagger UI should render all routes
```

## 4. Notes

- **Placeholder files** are intentionally minimal. They exist so that imports across packages work from day one. Each will be fleshed out by its own story.
- **`best.pt`** is NOT copied into `model_weights/` in this story. That's a manual step documented in the README (Story 7.5). The current `best.pt` at project root continues to work for the notebook.
- **No dependencies are installed** in this story beyond `fastapi` and `uvicorn`. Full dependency management is Story 1.2.
- **No `.env` or settings** are configured here. That's Story 1.3.
