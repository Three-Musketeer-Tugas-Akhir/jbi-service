# Story 2.6 — Validate Output Parity

| Field          | Value                                                                                              |
| -------------- | -------------------------------------------------------------------------------------------------- |
| **Epic**       | 2 — Core CV Pipeline Refactor                                                                      |
| **Priority**   | P0                                                                                                 |
| **Summary**    | Ensure API pipeline produces identical results to the notebook                                      |
| **Depends on** | 2.1 (detector), 2.2 (segmenter), 2.3 (cropper), 2.4 (pipeline), 2.5 (unit tests passing)         |
| **Blocks**     | Epic 3–5 (all API stories assume the pipeline is correct)                                          |

---

## 1. Objective

Run both the notebook and the refactored pipeline on the **same video** with the **same settings** and verify that the outputs are identical. This is the acceptance gate for Epic 2 — confirming that the refactor did not alter behavior.

"Identical" means:

1. The same seconds are detected as having objects.
2. The same segments are identified (same start/end times).
3. The same bounding boxes are used for cropping.
4. The exported video files have the same resolution, duration, and visual content.

---

## 2. Acceptance Criteria

| #    | Criteria                                                                                                   |
| ---- | ---------------------------------------------------------------------------------------------------------- |
| AC-1 | A validation script `tests/test_parity.py` exists that runs both paths and compares outputs.               |
| AC-2 | Per-second detection arrays match: `notebook_detections == pipeline_detections`.                            |
| AC-3 | Segment time ranges match: same number of segments with identical `(start, end)` pairs.                    |
| AC-4 | Bounding boxes match: `abs(notebook_bbox[i] - pipeline_bbox[i]) < 1.0` for all coordinates.               |
| AC-5 | Exported segment files match: same count, same resolution (W x H), duration within ±1s.                    |
| AC-6 | `detection_times.txt` content matches the notebook's `object_detection_times.txt`.                         |
| AC-7 | Validation passes on at least one reference video used during development.                                 |

---

## 3. Why Parity Validation Matters

The refactor touched every function in the notebook:

| Notebook Function                   | Refactored To                                | Risk of Behavior Change                          |
| ----------------------------------- | -------------------------------------------- | ------------------------------------------------ |
| `detect_objects_in_batch()`         | `DetectorService._detect_batch()`            | Batch boundary handling, bbox extraction order    |
| `rescale_bbox_to_original()`        | `DetectorService._rescale_bbox()`            | Low — direct port, but float precision            |
| `split_video()`                     | `identify_segments()`                        | Min-duration filter, end-of-video edge case       |
| `crop_frame_by_bbox()`              | `_crop_frame_by_bbox()`                      | Low — direct port                                 |
| `process_segment()`                 | `_export_segment()`                          | MoviePy API usage, codec params, temp file naming |
| Main `while` loop                   | `DetectorService.detect()`                   | Second stepping, batch remainder handling         |

The unit tests (Story 2.5) cover individual functions, but **integration-level differences** (e.g., a frame read order change causing different bbox selection) can only be caught by running the full pipeline end-to-end.

## 4. Detailed Implementation

### 4.1 Test Script — `tests/test_parity.py`

```python
"""
Output Parity Validation — Notebook vs Refactored Pipeline

This script runs the refactored pipeline on a reference video and compares
the output against pre-recorded notebook results (the "golden" baseline).

Prerequisites:
  - Model weights at model_weights/best.pt
  - A reference video file (path set via PARITY_VIDEO_PATH env var)
  - Golden baseline files generated from the notebook (see Section 4.2)

Usage:
  # Generate golden baseline first (see Section 4.2), then:
  PARITY_VIDEO_PATH=path/to/video.mp4 pytest tests/test_parity.py -v -s
"""

import json
import os
import math

import pytest
import cv2

from app.services.pipeline import run_pipeline

# Skip entire module if no reference video is configured
PARITY_VIDEO_PATH = os.environ.get("PARITY_VIDEO_PATH")
GOLDEN_DIR = os.environ.get("PARITY_GOLDEN_DIR", "tests/golden")

pytestmark = pytest.mark.skipif(
    not PARITY_VIDEO_PATH or not os.path.exists(PARITY_VIDEO_PATH or ""),
    reason="PARITY_VIDEO_PATH not set or file not found",
)


@pytest.fixture(scope="module")
def pipeline_result(tmp_path_factory):
    """Run the pipeline once for the entire test module."""
    output_dir_base = tmp_path_factory.mktemp("parity_output")
    result = run_pipeline(
        job_id="parity-test",
        video_path=PARITY_VIDEO_PATH,
    )
    return result


@pytest.fixture(scope="module")
def golden_data():
    """Load the golden baseline data generated from the notebook."""
    golden_path = os.path.join(GOLDEN_DIR, "golden_baseline.json")
    if not os.path.exists(golden_path):
        pytest.skip(f"Golden baseline not found: {golden_path}")
    with open(golden_path) as f:
        return json.load(f)


class TestDetectionParity:
    """Verify per-second detection results match the notebook."""

    def test_detection_array_length(self, pipeline_result, golden_data):
        """Same number of seconds scanned."""
        pipeline_len = len(pipeline_result.detection.detections)
        golden_len = golden_data["total_seconds"]

        # Allow ±1 second difference due to floor() rounding
        assert abs(pipeline_len - golden_len) <= 1, (
            f"Detection length mismatch: pipeline={pipeline_len}, golden={golden_len}"
        )

    def test_detection_array_match(self, pipeline_result, golden_data):
        """Per-second detection booleans match."""
        pipeline_det = pipeline_result.detection.detections
        golden_det = golden_data["detections"]

        # Compare up to the shorter length (±1s edge case)
        compare_len = min(len(pipeline_det), len(golden_det))
        mismatches = []

        for i in range(compare_len):
            if pipeline_det[i] != golden_det[i]:
                mismatches.append(i)

        # Allow ≤1% mismatch rate (floating-point confidence threshold edge cases)
        mismatch_rate = len(mismatches) / compare_len if compare_len > 0 else 0
        assert mismatch_rate <= 0.01, (
            f"{len(mismatches)} mismatches out of {compare_len} seconds "
            f"({mismatch_rate:.2%}): first 10 = {mismatches[:10]}"
        )


class TestSegmentationParity:
    """Verify segment identification matches the notebook."""

    def test_segment_count(self, pipeline_result, golden_data):
        """Same number of segments."""
        pipeline_count = len(pipeline_result.segmentation.segments)
        golden_count = len(golden_data["segments"])
        assert pipeline_count == golden_count, (
            f"Segment count mismatch: pipeline={pipeline_count}, golden={golden_count}"
        )

    def test_segment_time_ranges(self, pipeline_result, golden_data):
        """Start/end times match within ±1 second."""
        for i, (p_seg, g_seg) in enumerate(zip(
            pipeline_result.segmentation.segments, golden_data["segments"]
        )):
            assert abs(p_seg.start_seconds - g_seg["start"]) <= 1, (
                f"Segment {i} start mismatch: "
                f"pipeline={p_seg.start_seconds}, golden={g_seg['start']}"
            )
            assert abs(p_seg.end_seconds - g_seg["end"]) <= 1, (
                f"Segment {i} end mismatch: "
                f"pipeline={p_seg.end_seconds}, golden={g_seg['end']}"
            )

    def test_segment_bboxes(self, pipeline_result, golden_data):
        """Bounding boxes match within ±1 pixel."""
        for i, (p_seg, g_seg) in enumerate(zip(
            pipeline_result.segmentation.segments, golden_data["segments"]
        )):
            for j, (p_val, g_val) in enumerate(zip(p_seg.bbox, g_seg["bbox"])):
                assert abs(p_val - g_val) < 1.0, (
                    f"Segment {i} bbox[{j}] mismatch: "
                    f"pipeline={p_val}, golden={g_val}"
                )


class TestCropParity:
    """Verify exported video segments match the notebook output."""

    def test_export_file_count(self, pipeline_result, golden_data):
        """Same number of exported files."""
        pipeline_count = len(pipeline_result.crop.segments)
        golden_count = len(golden_data["segments"])
        assert pipeline_count == golden_count

    def test_export_resolution(self, pipeline_result, golden_data):
        """Exported video resolution matches expected bbox dimensions."""
        for cropped_seg in pipeline_result.crop.segments:
            cap = cv2.VideoCapture(cropped_seg.file_path)
            assert cap.isOpened(), f"Cannot open {cropped_seg.file_path}"

            width = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH))
            height = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT))
            cap.release()

            bbox_w = int(cropped_seg.bbox[2])
            bbox_h = int(cropped_seg.bbox[3])

            # Make even (same logic as _crop_frame_by_bbox)
            if bbox_w % 2 != 0:
                bbox_w -= 1
            if bbox_h % 2 != 0:
                bbox_h -= 1

            assert width == bbox_w, (
                f"Segment {cropped_seg.index} width: got {width}, expected {bbox_w}"
            )
            assert height == bbox_h, (
                f"Segment {cropped_seg.index} height: got {height}, expected {bbox_h}"
            )

    def test_export_duration(self, pipeline_result):
        """Exported clip duration matches segment time range (±1s)."""
        for cropped_seg in pipeline_result.crop.segments:
            cap = cv2.VideoCapture(cropped_seg.file_path)
            assert cap.isOpened()

            fps = cap.get(cv2.CAP_PROP_FPS)
            frames = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
            cap.release()

            if fps > 0:
                actual_duration = frames / fps
                expected_duration = cropped_seg.duration_seconds
                assert abs(actual_duration - expected_duration) <= 1.0, (
                    f"Segment {cropped_seg.index} duration: "
                    f"got {actual_duration:.1f}s, expected {expected_duration}s"
                )


class TestDetectionTimesParity:
    """Verify detection_times.txt matches notebook output."""

    def test_detection_times_content(self, pipeline_result, golden_data):
        """detection_times.txt matches golden reference."""
        with open(pipeline_result.detection_times_path) as f:
            pipeline_content = f.read().strip()

        golden_content = golden_data.get("detection_times_txt", "").strip()
        assert pipeline_content == golden_content, (
            f"detection_times.txt mismatch:\n"
            f"--- pipeline ---\n{pipeline_content}\n"
            f"--- golden ---\n{golden_content}"
        )
```

### 4.2 Golden Baseline Generator — `tests/generate_golden_baseline.py`

This script runs the **notebook logic** (not the refactored modules) to produce the golden baseline JSON. Run it once against the reference video.

```python
"""
Generate golden baseline from the original notebook logic.

Usage:
  python tests/generate_golden_baseline.py <video_path> [output_dir]

Outputs:
  tests/golden/golden_baseline.json
"""

import sys
import os
import json
import math
from datetime import timedelta

import cv2
import torch
from ultralytics import YOLO


def main():
    video_path = sys.argv[1]
    output_dir = sys.argv[2] if len(sys.argv) > 2 else "tests/golden"
    os.makedirs(output_dir, exist_ok=True)

    # --- Load model (same as notebook) ---
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    model = YOLO("best.pt").to(device)

    # --- Open video (same as notebook) ---
    cap = cv2.VideoCapture(video_path)
    fps = cap.get(cv2.CAP_PROP_FPS)
    frame_count = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
    duration = frame_count / fps

    # --- Detection loop (exact notebook logic) ---
    object_present_per_second = []
    segment_bboxes = {}
    batch_size = 8

    def rescale_bbox_to_original(bbox):
        x_center, y_center, w, h = bbox
        x_min = x_center - (w / 2)
        y_min = y_center - (h / 2)
        return [float(x_min), float(y_min), float(w), float(h)]

    second = 0
    while second < math.floor(duration):
        frames = []
        for i in range(batch_size):
            target_second = second + i
            if target_second >= math.floor(duration):
                break
            cap.set(cv2.CAP_PROP_POS_MSEC, target_second * 1000)
            ret, frame = cap.read()
            if not ret:
                continue
            frames.append(frame)

        if not frames:
            break

        results = model(frames, verbose=False)
        for idx, result in enumerate(results):
            has_det = len(result.boxes) > 0
            object_present_per_second.append(has_det)
            if has_det:
                yolo_bbox = result.boxes[0].xywh.cpu().numpy()[0]
                candidate_bbox = rescale_bbox_to_original(yolo_bbox)
                current_second = second + idx
                if current_second not in segment_bboxes:
                    segment_bboxes[current_second] = candidate_bbox

        second += batch_size

    cap.release()

    # --- Segmentation (exact notebook logic) ---
    segments = []
    start = None
    for s, present in enumerate(object_present_per_second):
        if present and start is None:
            start = s
        elif not present and start is not None:
            if s - start >= 5:
                segments.append((start, s))
            start = None
    if start is not None and len(object_present_per_second) - start >= 5:
        segments.append((start, len(object_present_per_second)))

    # --- Build golden baseline ---
    def seconds_to_time(secs):
        return str(timedelta(seconds=int(secs)))

    detection_times_lines = []
    segment_data = []
    for seg_start, seg_end in segments:
        bbox = segment_bboxes.get(seg_start, [0, 0, 0, 0])
        segment_data.append({
            "start": seg_start,
            "end": seg_end,
            "bbox": bbox,
        })
        detection_times_lines.append(
            f"{seconds_to_time(seg_start)} - {seconds_to_time(seg_end)}"
        )

    golden = {
        "video_path": video_path,
        "fps": fps,
        "frame_count": frame_count,
        "duration": duration,
        "total_seconds": len(object_present_per_second),
        "seconds_with_detection": sum(object_present_per_second),
        "detections": object_present_per_second,
        "segments": segment_data,
        "detection_times_txt": "\n".join(detection_times_lines),
    }

    out_path = os.path.join(output_dir, "golden_baseline.json")
    with open(out_path, "w") as f:
        json.dump(golden, f, indent=2)

    print(f"Golden baseline written to {out_path}")
    print(f"  Seconds scanned: {golden['total_seconds']}")
    print(f"  Seconds with detection: {golden['seconds_with_detection']}")
    print(f"  Segments: {len(golden['segments'])}")


if __name__ == "__main__":
    main()
```

## 6. Tolerance Rationale

| Comparison            | Tolerance  | Why                                                                                      |
| --------------------- | ---------- | ---------------------------------------------------------------------------------------- |
| Detection array length | ±1 second  | `math.floor(duration)` may differ by 1 due to float precision in `frame_count / fps`    |
| Detection booleans     | ≤1% mismatch | YOLO confidence scores near the threshold may flip between runs on different hardware  |
| Segment start/end      | ±1 second  | Follows from detection tolerance                                                         |
| Bounding box values    | <1.0 pixel | Float → int rounding in different NumPy versions                                        |
| Export duration        | ±1 second  | MoviePy/FFmpeg may differ in frame count by 1 at clip boundaries                        |
| Export resolution      | Exact match | Deterministic: `int(bbox_w)` with even-number enforcement                               |
| detection_times.txt    | Exact match | Deterministic: integer seconds → `timedelta` string                                     |

## 7. CI Integration

These tests are **not** part of the standard `pytest tests/` run. They require:
- A GPU or CPU capable of running YOLO inference
- The `best.pt` model file
- A reference video file

For CI, they should be a **separate stage** triggered manually or on model/pipeline changes:

```yaml
# Example GitHub Actions step (not part of this story)
- name: Parity validation
  if: github.event_name == 'workflow_dispatch'
  env:
    PARITY_VIDEO_PATH: tests/fixtures/reference_video.mp4
  run: pytest tests/test_parity.py -v -s
```

The regular `pytest tests/` run will skip `test_parity.py` automatically due to the `pytestmark = pytest.mark.skipif(...)` guard.

## 8. Notes

- **Golden baseline is committed to git** (`tests/golden/golden_baseline.json`). It's small (a JSON of booleans and coordinates) and serves as the reference for all future pipeline changes.
- **The reference video is NOT committed** — it's too large. Document which video was used in the JSON's `video_path` field.
- **Re-generate the golden baseline** whenever the YOLO model (`best.pt`) is retrained or the notebook logic is intentionally changed.
- **`generate_golden_baseline.py` uses raw notebook logic**, not the refactored modules. This ensures the baseline is independent of the code being tested.
