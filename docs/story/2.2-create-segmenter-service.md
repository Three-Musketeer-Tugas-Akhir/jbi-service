## 1. Objective

Extract the `split_video()` function and `seconds_to_time()` helper from `VideoDetector3.ipynb` into `app/services/segmenter.py`. This module must:

- Take a `DetectionResult` (from Story 2.1) and produce a list of `Segment` objects.
- Filter out segments shorter than `settings.min_segment_duration`.
- Attach the bounding box from the first detected frame to each segment.
- Generate the `detection_times.txt` equivalent as a string (not hardcoded file write).

## 4. Detailed Implementation

### 4.1 Data Classes

```python
from dataclasses import dataclass, field
from datetime import timedelta
import logging

from app.config import settings
from app.services.detector import DetectionResult

logger = logging.getLogger(__name__)


@dataclass
class Segment:
    """A single contiguous time range where the target object was detected."""
    index: int
    start_seconds: int
    end_seconds: int
    duration_seconds: int
    start_time: str    # formatted, e.g. "0:02:52"
    end_time: str      # formatted, e.g. "0:03:25"
    bbox: list[float]  # [x_min, y_min, width, height] from first detected frame


@dataclass
class SegmentationResult:
    """Complete output of the segmentation phase."""
    segments: list[Segment] = field(default_factory=list)
    total_seconds_scanned: int = 0
    seconds_with_detection: int = 0
```

### 4.2 Core Functions

```python
def identify_segments(detection_result: DetectionResult) -> SegmentationResult:
    """Identify contiguous detection segments from per-second detection data.

    This is a direct refactor of the notebook's split_video() function.
    It groups consecutive True values in detection_result.detections into
    segments, filters by min_segment_duration, and attaches bboxes.

    Args:
        detection_result: Output from DetectorService.detect().

    Returns:
        SegmentationResult with list of qualifying Segment objects.
    """
    detections = detection_result.detections
    bboxes = detection_result.bboxes
    min_duration = settings.min_segment_duration

    # --- Step 1: Find contiguous True runs ---
    raw_segments: list[tuple[int, int]] = []
    start = None

    for second, present in enumerate(detections):
        if present and start is None:
            start = second
        elif not present and start is not None:
            raw_segments.append((start, second))
            start = None

    # Handle case where detection runs to the end of the video
    if start is not None:
        raw_segments.append((start, len(detections)))

    # --- Step 2: Filter by minimum duration ---
    filtered = [
        (s, e) for s, e in raw_segments
        if (e - s) >= min_duration
    ]

    logger.info(
        "Segmentation: %d raw segments → %d after min_duration=%ds filter",
        len(raw_segments), len(filtered), min_duration,
    )

    # --- Step 3: Build Segment objects with bbox ---
    segments: list[Segment] = []

    for idx, (seg_start, seg_end) in enumerate(filtered):
        # Find bbox: use the first second in the segment that has a bbox
        bbox = _find_segment_bbox(seg_start, seg_end, bboxes)

        segment = Segment(
            index=idx,
            start_seconds=seg_start,
            end_seconds=seg_end,
            duration_seconds=seg_end - seg_start,
            start_time=_seconds_to_time(seg_start),
            end_time=_seconds_to_time(seg_end),
            bbox=bbox,
        )
        segments.append(segment)

        logger.debug(
            "Segment %d: %s → %s (%ds), bbox=%s",
            idx, segment.start_time, segment.end_time,
            segment.duration_seconds, bbox,
        )

    return SegmentationResult(
        segments=segments,
        total_seconds_scanned=len(detections),
        seconds_with_detection=sum(detections),
    )


def format_detection_times(segments: list[Segment]) -> str:
    """Generate detection_times.txt content as a string.

    Produces the same format as the notebook's file output:
        0:02:52 - 0:03:25
        0:05:10 - 0:06:00

    Args:
        segments: List of Segment objects.

    Returns:
        Multiline string with time ranges.
    """
    lines = []
    for seg in segments:
        lines.append(f"{seg.start_time} - {seg.end_time}")
    return "\n".join(lines)


# ----- Internal helpers -----

def _find_segment_bbox(
    start: int,
    end: int,
    bboxes: dict[int, list[float]],
) -> list[float]:
    """Find the bbox for a segment by checking the first available second.

    The notebook uses segment_bboxes.get(start_time), which grabs the bbox
    from the exact start second. We replicate that but also search forward
    in case the start second's frame failed to read (edge case).

    Returns [0, 0, 0, 0] if no bbox found (should not happen in practice).
    """
    for second in range(start, end):
        if second in bboxes:
            return bboxes[second]

    logger.warning("No bbox found for segment %d-%d", start, end)
    return [0.0, 0.0, 0.0, 0.0]


def _seconds_to_time(seconds: int) -> str:
    """Convert seconds to human-readable time string.

    Direct port of the notebook's seconds_to_time().
    Examples: 0 → "0:00:00", 172 → "0:02:52", 3661 → "1:01:01"
    """
    return str(timedelta(seconds=seconds))
```

from app.services.detector import DetectionResult, VideoMetadata

## 7. Design Decisions

| Decision                                        | Rationale                                                                                         |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| **Pure functions, no I/O**                      | Makes unit testing trivial — pass in data, assert output. No mocking needed.                     |
| **`_find_segment_bbox` searches forward**       | The notebook assumes `segment_bboxes.get(start_time)` always hits. In practice, a frame read can fail, so searching the next few seconds is more robust. |
| **`format_detection_times` returns string**      | The notebook writes directly to a file. Returning a string lets the pipeline or API decide where to write it (disk, response body, etc). |
| **`Segment.index` field**                       | Needed for the download URL (`/segments/{index}/download` in API contract 6.4).                  |
| **`SegmentationResult` wraps summary stats**    | The API results endpoint (Story 5.1) needs `total_seconds_scanned` and `seconds_with_detection` — bundling them avoids recalculating later. |

## 8. Notes

- This module has **zero external dependencies** beyond the Python standard library and the project's own dataclasses. No OpenCV, no torch, no YOLO.
- The `Segment.bbox` is always from the **first detected frame** in the segment, matching notebook behavior. Story 2.3 (cropper) uses this bbox to crop every frame in the segment.
- `min_segment_duration` defaults to `5` in config (Story 1.3). Changing it to `3` or `10` via `.env` will immediately affect segmentation without code changes.
